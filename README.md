An offline web app that turns any photo and caption into GTA 6-style cover art, built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC. Four multi-panel poster layouts, five Vice City colour grades, bold outlined lettering, and PNG export in 1080×1080, 1080×1350 and 1920×1080 — everything runs locally in the browser, photos never leave the machine. `main.ts` copies `app/` and `screenshots/` to the output directory and writes `dossier.json`.

Built by [V4ldoo](https://make.fun/r/f1z3jcpa) for make.fun.
